== Description ==
Simple white and black theme. This theme offers nine different filter effects for images and featured images. It also offers an effect that shows or hides the filter as the cursor hovers over the image. This is the classic version of the WhiteBlack theme. This theme runs in two columns. In this version, besides image filter effects, there are four widget areas, a menu area, an extra single column template for pages, an extra single column template for posts, custom logo, responsive design, the option to add copyright in the footer, a selector to show or hide the login link.
