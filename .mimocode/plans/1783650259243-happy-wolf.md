# Plan: Auto-approve MiMoCode via --dangerously-skip-permissions

## Problem
The cron pipeline sends upgrade requests to tmux session 0, but that session doesn't exist (only sessions 1 and 2 exist). Also, MiMoCode asks for approval before running commands, blocking automation.

## Solution
Two changes needed:

### 1. Fix cron script target session
- **File**: `/root/nginx-certbot/websites/hamidshariati.ir/games/check-requests.sh`
- **Change**: Line 66 — `tmux send-keys -t 0` → `tmux send-keys -t 1` (session 1 is where MiMoCode runs)

### 2. Restart MiMoCode with auto-approve flag
- Kill current MiMoCode in tmux session 1
- Restart with: `mimo --dangerously-skip-permissions --trust`
- This auto-approves all tool calls (bash, edit, write, etc.) without asking
